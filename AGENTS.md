# Cat Say Stop

A browser extension that forces users to take a 5-minute rest from browsing social media websites.

## Purpose

This extension monitors browsing activity on social media sites and, after a certain usage threshold, enforces a mandatory 5-minute break/cooldown period during which the user cannot access those sites.

## Key Behaviors

- Detects when the user is browsing social media websites
- Tracks time spent on social media
- Forces a 5-minute rest period when the usage limit is reached
- Blocks or restricts access to social media during the rest period
